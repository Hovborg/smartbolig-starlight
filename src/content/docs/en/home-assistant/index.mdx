Home Assistant is the world's most popular open source smart home platform. Combine all your devices in one app - completely without cloud dependency.

<Aside type="note" title="Open Source">
Home Assistant is open source! Check out [Home Assistant on GitHub](https://github.com/home-assistant/core) for development and [HACS](https://github.com/hacs/integration) for community integrations.
</Aside>

### Which method should I choose?

| Method | Best for | Difficulty | Add-ons |
|--------|----------|------------|---------|
| **Raspberry Pi** | Beginners, dedicated device | ⭐ Easy | ✅ Yes |
| **Proxmox VM** | Home server, homelab | ⭐⭐ Medium | ✅ Yes |
| **Docker** | NAS, existing server | ⭐⭐⭐ Advanced | ❌ No |

<Aside type="tip" title="Not sure?">
- **Completely new?** → Raspberry Pi
- **Have a Proxmox server?** → Proxmox VM
- **Have NAS/Docker?** → Docker
</Aside>
