**Home Assistant Community Store (HACS)** gives you access to community-developed integrations, themes, and dashboard cards. HACS is almost a must-have for all Home Assistant users.

<Aside type="caution" title="From Home Assistant 2026.11, HACS is called Marketplace">
Home Assistant 2026.11 (released 4 November 2026) moved HACS into Home Assistant as the **Marketplace** under **Settings → Marketplace**. The HACS installer stops at 2026.11, so HACS can no longer be installed separately, and the old HACS will not get new releases. If you have HACS installed, Home Assistant migrates it automatically at startup: installed projects, custom repositories and update entities carry over, and HACS links open the Marketplace. This guide covers both the Marketplace and the older HACS installation.
</Aside>


<Aside type="tip">
Everything in the Marketplace and HACS is made by the community. The projects are not tested, audited or supported by the Home Assistant project. Always create a backup before you install anything!
</Aside>

## What is HACS?

HACS works as an "app store" for Home Assistant, where you can:

- **Discover** new custom integrations and components
- **Install** with just a few clicks directly from the UI
- **Update** everything from one place
- **Manage** your installed projects

## Prerequisites

Before you start, you need:

- ✅ Home Assistant running (OS, Supervised, Container or Core)
- ✅ A free [GitHub account](https://github.com/signup) (only needed for custom repositories in the Marketplace and for HACS before 2026.11)
- ✅ Access to Home Assistant web interface
- ✅ A backup of your system

<Aside type="caution">
Custom components run directly in Home Assistant and can affect stability. There's always a small risk that something can go wrong - always create a backup first!
</Aside>

## Marketplace (Home Assistant 2026.11 and newer)

The Marketplace comes with Home Assistant, so there is nothing to install. Only administrators can open it.

<Steps>
1. Update to Home Assistant 2026.11 or newer. If you already have HACS, you don't need to do anything
2. Open **Settings → Marketplace**
3. The first time, accept a warning that the content is made and published by the community and is not tested, audited or supported by the Home Assistant project
4. Use **Filters** to show only integrations, dashboards, themes, templates or only installed projects
5. Open a repository, select **Install**, check the version and confirm
</Steps>

- An integration opens its setup page when it can be loaded right away. Some integrations, for example those that use YAML configuration, need a restart, and updates take effect after a restart.
- Dashboards need a browser reload. Themes and templates load automatically.
- You add custom repositories with **Add from link** (a GitHub URL or `owner/repository`). The repository must be public and contain a `hacs.json` file. This requires connecting the Marketplace to GitHub through GitHub's device sign-in, which does not give access to private repositories.
- Browsing, installing and updating content from the catalog does not require GitHub.
- Installed projects get update entities and appear under **Settings → Updates**.
- Bookmarks to `/hacs` open the Marketplace.

Sources: [Home Assistant 2026.11](https://www.home-assistant.io/blog/2026/11/04/release-202611/) and the [Marketplace integration](https://www.home-assistant.io/integrations/marketplace/).

## Installation before 2026.11 (HACS)

If you run an older Home Assistant version, install HACS as described below. The installation method depends on your Home Assistant installation type. You can see your type under **Settings → About**.

### Container/Core Installation

If you're running Home Assistant Container or Core (before 2026.11), run this script:

```bash
# Run in your Home Assistant config directory
wget -O - https://get.hacs.xyz | bash -
```

Then restart Home Assistant and continue from step 6 above.

## Install Your First Integration

Let's install a popular integration as an example:

<Steps>
1. Open **Settings → Marketplace**
2. Search for e.g. "Energi Data Service" (Danish electricity price integration). If it isn't in the catalog, you can add it with **Add from link** and `MTrab/energidataservice`
3. Open the integration and read the description
4. Select **Install**, check the version and confirm
5. Open the integration's setup, or add it via Settings → Devices & Services → Add integration
</Steps>

<Aside type="tip">
In the Marketplace a new integration normally doesn't need a restart, but some do (for example those with YAML configuration). In HACS before 2026.11 you had to restart Home Assistant after downloading: sidebar **HACS** → **Integrations** → **+ Explore & download repositories** → **Download**.
</Aside>

## Updating HACS Components

HACS makes it easy to keep everything updated:

<Steps>
1. Go to **Settings → Updates**
2. Find the installed project with an available update
3. Click **Update** and follow the instructions
4. Restart Home Assistant if required
</Steps>

Installed projects in the Marketplace get update entities, so updates appear in Home Assistant's normal update overview. They did in HACS 2.0 too, where you could also use HACS in the sidebar.

## Troubleshooting

### Marketplace or HACS doesn't show

- The Marketplace requires Home Assistant 2026.11 or newer and an administrator user
- Make sure you've restarted Home Assistant
- Clear browser cache (Ctrl+F5)
- HACS before 2026.11: check that HACS files are in `custom_components/hacs/`

### GitHub API limit

The Marketplace and HACS use the GitHub API, which has limitations. If you get errors:

- Wait 1 hour and try again
- Make sure your GitHub account is properly connected. The connection raises the request limit

### Integration doesn't work after download

1. Check that you've restarted Home Assistant
2. Check the log under **Settings → System → Logs**
3. Read the integration's documentation on GitHub
4. Search for solutions in Home Assistant Community forum
