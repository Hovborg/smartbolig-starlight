## Today's Stories

### 1. Claude Code releases: v2.1.239

**What changed:** Claude Code releases published the update on 21 Aug 2026. Claude Code 2.1.239 adds a 1.1x premium for US-only inference to cost estimates in /cost, the status line and --max-budget-usd for data-residency workspaces. Bedrock, Vertex, Foundry and other previously excluded setups now get a one-time fullscreen renderer offer, so new installs there start in fullscreen. A new /claude-api upgrade command migrates Python projects from anthropic package version 0.x to 1.x, including changed timeout handling.

> Short source excerpt: What's changed Cost estimates &#40; /cost , status line, --max-budget-usd &#41; now include the 1.1× US-only-inference premium for data-residency workspaces…

**Why it matters:** Teams with data-residency requirements will see Claude Code cost more in practice, since US-only inference now carries an extra premium. Python developers using the Anthropic API get an official path to upgrade without manually rewriting timeout calls.

**How to verify it:** Check your organization's /cost output or status line after updating to see whether the new 1.1x premium appears, and run /claude-api upgrade in a test environment before migrating production code.

**Uncertainty:** It's unclear which countries or regions count as data-residency workspaces, or whether the premium is permanent. The source also doesn't show whether the Python migration covers every project type.

Source: [v2.1.239](https://github.com/anthropics/claude-code/releases/tag/v2.1.239)

### 2. OpenAI Codex releases: 0.150.0

**What changed:** OpenAI Codex releases published the update on 26 Aug 2026. OpenAI Codex 0.150.0 lets you reference other Codex tasks with @ mentions, so agents can read, create or message tasks directly from the terminal. The /copy command now offers a picker for full responses, individual code blocks or blockquotes. Unnamed terminal tasks automatically receive descriptive titles, and /rename suggests an editable title based on the conversation. Markdown links appear as clickable labels in terminals that support it, while visible URLs are kept elsewhere.

> Short source excerpt: New Features Reference other Codex tasks with @ mentions, and ask agents to read, create, or message tasks from the…

**Why it matters:** It makes it easier to track and coordinate multiple running Codex agents from the terminal without switching interfaces. Copying individual code blocks becomes more precise, and clickable links save manual copy-pasting.

**How to verify it:** Update the Codex CLI to 0.150.0 and test @ mentions against a running task, and check that /copy shows the new picker, in your preferred terminal.

**Uncertainty:** The source doesn't specify which terminals support clickable links, or whether @ mentions work across projects and machines. The reliability of automatic title generation isn't described either.

Source: [0.150.0](https://github.com/openai/codex/releases/tag/rust-v0.150.0)

### 3. OpenClaw releases: OpenClaw 2026.8.1-beta.3

**What changed:** OpenClaw releases published the update on 24 Aug 2026. OpenClaw 2026.8.1-beta.3 adds support for the GPT-5.6 models Sol, Terra, Luna and Ultra in both OpenClaw and the Codex runtime. The Control UI first-run setup now continues from model setup into Custodian and optional channel setup. It adds a Puppeteer-compatible CDP relay for paired Chrome sessions, explicit lifecycle supervision for external Gateway processes with restart handoff, and commands for SQLite backup and restore to a fresh target.

> Short source excerpt: Highlights GPT-5.6 Sol, Terra, Luna, and Ultra reasoning support across OpenClaw and the Codex runtime. Control UI first-run setup now…

**Why it matters:** More model variants let you pick a reasoning level per task, while the Chrome relay opens browser control to existing Puppeteer scripts. The backup and restart features can make a self-hosted OpenClaw setup less fragile when something fails.

**How to verify it:** This is a beta release, so test the SQLite backup and restore on a copy of your data, and confirm the GPT-5.6 model you expect to use is actually available in your setup.

**Uncertainty:** As a beta, features may change or contain bugs. The source doesn't show pricing or access limits for the GPT-5.6 models, and it doesn't say whether the CDP relay requires special Chrome configuration.

Source: [OpenClaw 2026.8.1-beta.3](https://github.com/openclaw/openclaw/releases/tag/v2026.8.1-beta.3)
