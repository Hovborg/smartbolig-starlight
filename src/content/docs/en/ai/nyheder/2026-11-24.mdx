### 1. OpenAI Codex releases: 0.172.0

**What changed:** OpenAI Codex releases published the update on 24 Nov 2026. Version 0.172.0 of OpenAI Codex adds thread links that open saved conversations and nested agents in the terminal, Tab completion for arguments of supported slash commands, and Shift+Up and Shift+Down to jump between task groups in the agent command center. Optional stdio MCP servers with cached tool lists now start on their first tool call by default. An approval reviewer can be set for individual connected app tools in config.toml, and app-server clients can select Amazon Bedrock Runtime during setup or sign-in.

> Short source excerpt: New Features Follow thread links from search results and transcripts to open saved conversations and nested agents in the terminal.…

**Why it matters:** The source describes these as changes for people working in the Codex terminal and for app-server clients. It states that resuming codex exec restores saved sandbox permissions, the working directory and workspace roots unless explicitly overridden, and that remote sessions preserve working directories, workspace roots and writable paths when client and server run on different operating systems.

**How to verify it:** Check the installed version against 0.172.0, then read the release notes for the entries listed here. In the terminal, type a supported slash command such as /mcp lo and press Tab to see whether it completes to /mcp login, as the source describes.

### 2. Claude Code releases: v2.1.331

**What changed:** Claude Code releases published the update on 23 Nov 2026. Claude Code v2.1.331 adds Code Mode support in terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and Claude Platform on AWS. It adds an API connectivity section to claude doctor, a notice when tap-mode voice dictation stops by itself after 15 seconds without recognized speech or at its 2-minute limit, and optionalDependencies in plugin manifests. It also fixes MCP tool calls hanging for up to 30 minutes on some malformed replies from a local or WebSocket server.

> Short source excerpt: What's changed Added Code Mode support in terminal sessions on Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and Claude…

**Why it matters:** The changes target Claude Code users working through cloud providers such as Amazon Bedrock, Google Cloud's Agent Platform, Microsoft Foundry and Claude Platform on AWS, plus administrators of Claude apps gateways. The source notes that the new uncompressed-response setting is not advised yet for self-hosted runners or Remote Control.

**How to verify it:** Run claude doctor and look for the new API connectivity section, which reports whether the API can be reached, with the HTTP status or the error, or says why it was not tested.

**Uncertainty:** The text is truncated and does not say when the version reaches all users, in which regions the cloud Code Mode support is available, or whether the new environment variables are on by default.

Source: [v2.1.331](https://github.com/anthropics/claude-code/releases/tag/v2.1.331)

### 4. Google AI Blog: A more tailored Google Search that’s uniquely yours

**What changed:** Google AI Blog published the update on 23 Nov 2026. Google is starting to roll out an opt-in connection between Google Wallet and Personal Intelligence in AI Mode, with support for Google Drive and the Gemini app following in the coming weeks. The company says Search can then use context from spending, documents and chats. Wallet and Drive join Gmail, Calendar and Photos. Users connect apps through Search Personalization and Connected Apps.

> Short source excerpt: Get more helpful Search responses by securely opting in to connect Google Wallet, Drive, and the Gemini app to Personal…

**How to verify it:** To check availability, open Search Personalization and select Connected Apps, as the source describes, and see which apps you can choose to connect. The source says Wallet is rolling out first, with Drive and the Gemini app following in the coming weeks.

**Uncertainty:** The text does not say which countries or how many users get the Wallet connection at launch, the exact dates for Drive and the Gemini app, or whether the features will be free. It also does not detail limits on what data AI Mode can read beyond Wallet being read-only.
