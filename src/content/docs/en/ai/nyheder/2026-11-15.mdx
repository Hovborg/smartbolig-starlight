### 2. Claude Code releases: v2.1.323

**What changed:** Claude Code releases published the update on 12 Nov 2026. Claude Code v2.1.323 adds Code Mode, an experimental opt-in where Claude writes JavaScript to call its tools. Plugins can now declare an engines field for claude-code in plugin.json, and plugins outside their stated version range are not installed, updated or loaded. The claude plugin validate command now type checks a plugin's TypeScript hooks module, with each finding a warning and --strict failing on it. Artifact tool asset uploads now accept .docx files.

> Short source excerpt: What's changed Added Code Mode, an experimental opt-in in which Claude writes JavaScript to call its tools; see https://<wbr/>code.claude.com/docs/en/code-mode to…

**Why it matters:** Plugins outside their declared Claude Code version range are not installed, updated or loaded, and install and update pick the newest version that fits. A progress heartbeat every 30 seconds during long hooks in claude -p and SDK sessions keeps a host such as Claude Desktop from ending the turn as hung, once it includes this version.

**How to verify it:** Check the installed version and read the release notes for v2.1.323. To see whether Code Mode is on, the source points to the Code Mode documentation page, which describes how to turn it on or turn it off for an organization.

**Uncertainty:** The text is truncated and does not say when Code Mode leaves experimental status, which plans or regions get it, or whether the plugin version range applies to plugins already installed. It also gives no price.
