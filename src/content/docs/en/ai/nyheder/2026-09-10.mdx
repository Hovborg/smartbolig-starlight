**How to verify it:** Update Codex to version 0.154.0, check the model picker to see if GPT-6-Astra is available on your account, and try --worktree on a test session.

### 2. Claude Code releases: v2.1.268

**What changed:** Claude Code releases published the update on 10 Sept 2026. Claude Code 2.1.268 lets signed-in clients on an organization's Claude apps gateway receive the pricing set in gateway.yaml, so /cost and telemetry match actual spend. The release adds a startup warning when access&#95;control.allow&#95;cidrs is empty, plus a one-time warning the first time a request arrives from a public address. It also adds a gatewayInternalNetworks setting for administrators to control gateway login.

> Short source excerpt: What's changed Added to the Claude apps gateway: with pricing: set in gateway.yaml , signed-in Claude Code clients receive the…

**Why it matters:** The change targets organizations that run their own Claude gateway. Accurate pricing sync makes usage figures reliable, and the warnings about empty access lists reduce the risk of a gateway being left open to the public by mistake.

**How to verify it:** If your organization runs a Claude gateway, check gateway.yaml for the pricing field and confirm access&#95;control.allow&#95;cidrs is actually filled in before you update.

**Uncertainty:** The source does not describe what happens if the pricing field is missing, or how this affects ordinary single users without a gateway setup.

### 4. Gemini CLI releases: Release v0.60.0-preview.0

**What changed:** Gemini CLI releases published the update on 8 Sept 2026. Gemini CLI v0.60.0-preview.0 fixes destination validation and connection routing in the CLI's web fetch utility and enforces RFC 9207 issuer identification in the MCP OAuth flow. The release also isolates the temporary directory used by macOS's Seatbelt sandbox, so sessions no longer share the same temp space.

> Short source excerpt: What's Changed fix&#40;core&#41;: improve destination validation and connection routing in web fetch utilities by @diegogodinezr in #29120 fix&#40;core&#41;: enforce RFC…

**Why it matters:** The fixes close potential security gaps: stricter web fetch validation reduces the risk of being redirected to unexpected destinations, and the tighter OAuth check makes it harder to spoof an issuer in MCP integrations. The macOS isolation reduces the risk of sessions unintentionally sharing files.

**How to verify it:** Update to v0.60.0-preview.0 and check the version with gemini --version if you use MCP connections or web fetch in your setup.

**Uncertainty:** This is a preview release, so stability is not guaranteed, and the source does not show whether the fixes have already affected users in practice.

Source: [Release v0.60.0-preview.0](https://github.com/google-gemini/gemini-cli/releases/tag/v0.60.0-preview.0)
