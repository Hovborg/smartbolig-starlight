### 2. Claude Code releases: v2.1.212

**What changed:** Claude Code releases published the update on 17 Jul 2026. Claude Code v2.1.212 changes how fork works: it now copies your conversation into a new background session with its own row under claude agents, while the subagent it used to launch in-session is now called subtask. The update adds a command to reset auto-mode to its default configuration, with a confirmation prompt unless you pass a skip flag. It also adds a session-wide cap on WebSearch calls, defaulting to 200 and adjustable via an environment variable, to stop runaway search loops.

> Short source excerpt: What's changed /fork now copies your conversation into a new background session &#40;its own row in claude agents &#41; while…

**Why it matters:** If you use fork to branch conversations, expect a background session instead of an inline subagent, which changes how you track and resume that work. The WebSearch cap protects against a session silently burning through search quota if an agent loops.

**How to verify it:** Update to v2.1.212, run fork once and check claude agents for the new background session row, and confirm subtask now appears where the old inline subagent used to run.

**Uncertainty:** The source text cuts off before describing the per-session subagent cap in full, so its exact limit and effect are not stated. Whether the new WebSearch default of 200 suits heavier workflows is not addressed.

Source: [v2.1.212](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)
