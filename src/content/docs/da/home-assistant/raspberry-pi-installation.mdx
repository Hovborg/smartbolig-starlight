Raspberry Pi er den mest populære måde at køre Home Assistant på. Billigt, støjsvagt og bruger kun 5-10W strøm.

![Raspberry Pi setup diagram](/images/guides/raspberry-pi/setup.svg)

## 📋 Forudsætninger

- ✅ Raspberry Pi 4 (2GB+) eller Pi 5
- ✅ Computer til at flashe SD-kort
- ✅ Netværk med internet

## 🛒 Hardware

| Del | Beskrivelse | Pris ca. |
|-----|-------------|----------|
| Raspberry Pi 4 (4GB) | Anbefalet model | 450 kr |
| Strømforsyning | Official 15W USB-C | 100 kr |
| SD-kort 32GB+ (A2) | Samsung EVO eller SanDisk | 80 kr |
| Ethernetkabel | Cat5e/Cat6 | 30 kr |
| **Total** | | **~660 kr** |

### Valgfrit (men anbefalet)

| Del | Hvorfor | Pris ca. |
|-----|---------|----------|
| SSD + USB adapter | Hurtigere, holder længere | 200 kr |
| Køleplade/blæser | Holder Pi'en kølig | 50 kr |
| Case | Beskyttelse og æstetik | 100 kr |

<Aside type="caution" title="⚠️ SD-kort holder ikke evigt">
SD-kort dør efter 1-3 år med Home Assistant. Brug SSD fra starten hvis muligt, eller hav altid en backup klar.
</Aside>

## 📥 Download og Flash

<Steps>
1. **Download Raspberry Pi Imager**
   
   Hent fra [raspberrypi.com/software](https://www.raspberrypi.com/software/)

2. **Sæt SD-kort i computeren**

3. **Åbn Raspberry Pi Imager**

4. **Vælg operativsystem:**
   - Klik **"Choose OS"**
   - Scroll ned til **"Other specific-purpose OS"**
   - Vælg **"Home assistants and home automation"**
   - Vælg **"Home Assistant"**
   - Vælg **"Home Assistant OS X.X (RPi 4/5)"**

5. **Vælg dit SD-kort:**
   - Klik **"Choose Storage"**
   - Vælg dit SD-kort (pas på - vælg den rigtige!)

6. **Flash:**
   - Klik **"Write"**
   - Bekræft at data slettes
   - Vent til skrivningen er færdig
</Steps>

<Aside type="tip">
Du behøver IKKE konfigurere WiFi eller SSH i Imager. Home Assistant OS håndterer alt selv.
</Aside>

## 🔌 Hardware Setup

![Raspberry Pi setup diagram](/images/guides/raspberry-pi/setup.svg)

<Steps>
1. **Sæt SD-kortet i Raspberry Pi**
   
   Kortslotten er på undersiden af boardet.

2. **Tilslut Ethernet kabel**
   
   Direkte til din router for mest stabil forbindelse.

3. **Tilslut strøm (sidst!)**
   
   Brug den officielle strømforsyning. Billige opladere kan give problemer.
</Steps>

<Aside type="note">
Siden på homeassistant.local:8123 kan normalt nås inden for få minutter (på en Pi 4 eller 5 inden for ét minut). Sluk IKKE for strømmen mens du venter!
</Aside>

## 🌐 Åbn Home Assistant

<Tabs>
  <TabItem label="Automatisk (nemmest)">
    Åbn din browser og gå til:
    
    ```
    http://homeassistant.local:8123
    ```
  </TabItem>
  <TabItem label="Via IP-adresse">
    Hvis `homeassistant.local` ikke virker:
    
    1. Find Pi'ens IP i din router (ofte under "DHCP clients" eller "Connected devices")
    2. Åbn: `http://192.168.X.XXX:8123`
  </TabItem>
</Tabs>

Du ser først **"Preparing Home Assistant"**, mens nyeste version hentes - det kan tage 20 minutter eller mere, afhængigt af hardware og internetforbindelse.

## ⚙️ Første Opsætning

<Steps>
1. **Opret din konto**
   
   - Vælg et brugernavn
   - Brug et **stærkt password** (gem det i password manager!)

2. **Navngiv dit hjem**
   
   F.eks. "Mit Hjem" eller din adresse.

3. **Angiv lokation**
   
   Bruges til solopgang/nedgang, vejr og tidszone.

4. **Vælg hvad du vil dele**
   
   Anonyme statistikker - helt frivilligt.

5. **Opdagede enheder**
   
   Home Assistant finder automatisk enheder på dit netværk. Klik "Finish" for nu.
</Steps>

🎉 **Tillykke!** Home Assistant kører nu.

## 🛡️ Vigtige første trin

### 1. Lav backup

<Steps>
1. Gå til **Indstillinger** → **System** → **Backups**
2. Klik **"Opret backup"**
3. Download backup-filen til din computer
</Steps>

<Aside type="danger">
Gem ALDRIG kun backups på SD-kortet. Hvis kortet dør, mister du alt!
</Aside>

### 2. Opdater Home Assistant

<Steps>
1. Gå til **Indstillinger** → **System** → **Opdateringer**
2. Opdater alt der er tilgængeligt
3. Genstart hvis nødvendigt
</Steps>

### 3. Installer nyttige apps

Gå til **Indstillinger** → **Apps** → **Install app** (hed før Home Assistant 2026.2 *Add-ons*):

| App | Hvad gør den |
|--------|--------------|
| **File Editor** | Rediger config-filer i browseren |
| **Terminal & SSH** | Kommandolinje-adgang |
| **Samba share** | Adgang til filer fra Windows/Mac |

## 🔧 Fejlfinding

<Aside type="tip" title="homeassistant.local virker ikke?">
**Prøv disse ting:**
1. Vent et par minutter mere og prøv igen
2. Find IP i din router og brug `http://IP:8123`
3. Prøv en anden browser
4. Tjek at Pi'en har grønt lys (strøm) og blinkende lys (aktivitet)
</Aside>

<Aside type="tip" title="'Preparing Home Assistant' tager evigt?">
**Normal tid:** op til 20 minutter eller mere, afhængigt af hardware og internetforbindelse.

**Hvis siden slet ikke dukker op efter 5 minutter (Pi 4 eller 5):**
- Tjek at Pi'en har internet (ethernet kabel sat i?)
- Tilslut en skærm via HDMI og se konsollens output
- Flash kortet igen, eventuelt med et andet SD-kort

Flash ikke kortet igen, mens "Preparing Home Assistant" vises.
</Aside>

<Aside type="tip" title="Pi'en bliver meget varm?">
Raspberry Pi 4/5 kan blive 70-80°C under belastning.

**Løsning:**
- Monter køleplade (passiv køling)
- Brug case med blæser (aktiv køling)
- Tjek temperatur i HA under **Indstillinger** → **System** → **Hardware**
</Aside>

## 💾 Opgrader til SSD (anbefalet)

SD-kort er den #1 årsag til Home Assistant problemer. En SSD koster ~200 kr og holder i mange år.

### Hvad du skal bruge

- USB 3.0 til SATA adapter eller SSD enclosure
- 2.5" SATA SSD (120GB er rigeligt)

### Sådan gør du

<Steps>
1. Flash Home Assistant OS til SSD'en (samme metode som SD-kort)
2. Sluk Pi'en
3. Fjern SD-kortet
4. Tilslut SSD via USB 3.0 port (blå port)
5. Tænd Pi'en
</Steps>

<Aside type="note">
Raspberry Pi 4 og 5 kan boote direkte fra USB. Ingen SD-kort nødvendigt!
</Aside>
