**Home Assistant Community Store (HACS)** giver dig adgang til community-udviklede integrationer, themes og dashboard-kort. HACS er næsten et must-have for alle Home Assistant brugere.

<Aside type="caution" title="Fra Home Assistant 2026.11 hedder HACS Marketplace">
Home Assistant 2026.11 (udgivet 4. november 2026) har flyttet HACS ind i Home Assistant som **Marketplace** under **Indstillinger → Marketplace**. Installationsprogrammet til HACS stopper ved 2026.11, så HACS kan ikke længere installeres separat, og det gamle HACS får ikke nye udgaver. Opdaterer du med HACS installeret, migrerer Home Assistant det automatisk ved opstart: installerede projekter, egne repositories og opdateringsentiteter følger med, og HACS-links åbner Marketplace. Guiden beskriver både Marketplace og den ældre HACS-installation.
</Aside>

<Aside type="tip">
Alt i Marketplace og HACS er lavet af community'et. Projekterne er ikke testet, auditeret eller understøttet af Home Assistant-projektet. Lav altid backup, før du installerer noget!
</Aside>

## Hvad er HACS?

HACS fungerer som en "app store" for Home Assistant, hvor du kan:

- **Opdage** nye custom integrationer og komponenter
- **Installere** med få klik direkte fra brugerfladen  
- **Opdatere** alt fra ét sted
- **Administrere** dine installerede projekter

## Forudsætninger

Før du starter, skal du have:

- ✅ Home Assistant kørende (OS, Supervised, Container eller Core)
- ✅ En gratis [GitHub konto](https://github.com/signup) (kun nødvendig til egne repositories i Marketplace og til HACS før 2026.11)
- ✅ Adgang til Home Assistant webinterface
- ✅ En backup af dit system

<Aside type="caution">
Custom komponenter kører direkte i Home Assistant og kan påvirke stabiliteten. Der er altid en lille risiko for at noget kan gå galt - lav derfor altid backup først!
</Aside>

## Marketplace (Home Assistant 2026.11 og nyere)

Marketplace følger med Home Assistant, så der er ikke noget at installere. Kun administratorer kan åbne den.

<Steps>
1. Opdater til Home Assistant 2026.11 eller nyere. Har du HACS i forvejen, behøver du ikke gøre noget
2. Åbn **Indstillinger → Marketplace**
3. Første gang skal du acceptere en advarsel om, at indholdet er lavet og udgivet af community'et og ikke er testet, auditeret eller understøttet af Home Assistant-projektet
4. Brug **Filters** til kun at se integrationer, dashboards, temaer, skabeloner eller kun installerede projekter
5. Åbn et repository, vælg **Install**, kontrollér versionen og bekræft
</Steps>

- En integration åbner sin opsætningsside, når den kan indlæses med det samme. Nogle integrationer, fx dem der bruger YAML-konfiguration, kræver genstart, og opdateringer træder i kraft efter en genstart.
- Dashboards kræver, at du genindlæser browseren. Temaer og skabeloner indlæses automatisk.
- Egne repositories tilføjer du med **Add from link** (GitHub-URL eller `ejer/repository`). Repositoryet skal være offentligt og indeholde en `hacs.json`. Det kræver, at du forbinder Marketplace med GitHub via GitHubs device-login, som ikke giver adgang til private repositories.
- Det kræver ikke GitHub at gennemse, installere og opdatere indhold fra kataloget.
- Installerede projekter får opdateringsentiteter og vises under **Indstillinger → Opdateringer**.
- Bogmærker til `/hacs` åbner Marketplace.

Kilder: [Home Assistant 2026.11](https://www.home-assistant.io/blog/2026/11/04/release-202611/) og [Marketplace-integrationen](https://www.home-assistant.io/integrations/marketplace/).

### Container/Core Installation

Hvis du kører Home Assistant Container eller Core (før 2026.11), skal du køre dette script:

```bash
# Kør i din Home Assistant config mappe
wget -O - https://get.hacs.xyz | bash -
```

Genstart derefter Home Assistant og fortsæt fra trin 6 ovenfor.

## Installer din første integration

Lad os installere en populær integration som eksempel:

<Steps>
1. Åbn **Indstillinger → Marketplace**
2. Søg efter f.eks. "Energi Data Service" (dansk elpris-integration). Findes den ikke i kataloget, kan du tilføje den med **Add from link** og `MTrab/energidataservice`
3. Åbn integrationen og læs beskrivelsen
4. Vælg **Install**, kontrollér versionen og bekræft
5. Åbn integrationens opsætning, eller tilføj den via Indstillinger → Enheder og tjenester → Tilføj integration
</Steps>

<Aside type="tip">
I Marketplace kræver en ny integration normalt ikke genstart, men nogle gør (fx dem med YAML-konfiguration). I HACS før 2026.11 skulle du genstarte Home Assistant efter download: sidemenu **HACS** → **Integrationer** → **+ Udforsk og download repositories** → **Download**.
</Aside>

## Opdatering af HACS komponenter

HACS gør det nemt at holde alt opdateret:

<Steps>
1. Gå til **Indstillinger → Opdateringer**
2. Find det installerede projekt med en tilgængelig opdatering
3. Klik **Opdater** og følg instruktionerne
4. Genstart Home Assistant, hvis påkrævet
</Steps>

Installerede projekter i Marketplace får opdateringsentiteter, så opdateringer vises i Home Assistants normale opdateringsoversigt. Det gjorde de også i HACS 2.0, hvor du desuden kunne bruge HACS i sidemenuen.

## Fejlfinding

### Marketplace eller HACS vises ikke

- Marketplace kræver Home Assistant 2026.11 eller nyere og en administratorbruger
- Sørg for at du har genstartet Home Assistant
- Ryd browser-cache (Ctrl+F5)
- HACS før 2026.11: tjek at HACS-filerne ligger i `custom_components/hacs/`

### GitHub API limit

Marketplace og HACS bruger GitHub API'en, som har begrænsninger. Hvis du får fejl:

- Vent 1 time og prøv igen
- Sørg for at din GitHub-konto er korrekt forbundet. Forbindelsen hæver grænsen for antal forespørgsler

### Integration virker ikke efter download

1. Tjek at du har genstartet Home Assistant
2. Tjek loggen under **Indstillinger → System → Logs**
3. Læs integrationens dokumentation på GitHub
4. Søg efter løsninger i Home Assistant Community forum
