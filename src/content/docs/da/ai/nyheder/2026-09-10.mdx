### 1. OpenAI Codex releases: 0.154.0

**Hvad ændrede sig:** OpenAI Codex releases offentliggjorde opdateringen 9. sep. 2026. Codex 0.154.0 tilføjer modellen GPT-6-Astra til modelvælgeren og til Amazon Bedrock-kataloget. Udgivelsen introducerer også eksperimentel worktree-støtte, hvor du med --worktree eller /worktree kan oprette isolerede checkouts til nye eller forgrenede sessioner og senere gennemse og genoptage dem. Desuden kan du nu besvare spørgsmål undervejs, mens Codex fortsætter arbejdet, ved hjælp af foreslåede svar eller egen tekst, uden at miste dit hovedudkast.

> Kort kildeuddrag: New Features GPT-6-Astra is now available in the model picker and Amazon Bedrock catalogs. &#40; #42879 , #42619 &#41; Experimental…

**Hvorfor det er relevant:** For folk der bruger Codex til kodning giver flere modelvalg mulighed for at sammenligne resultater og priser. Worktree-støtten gør det lettere at køre flere sessioner parallelt uden at sessionerne blander filer sammen, og inline-svar betyder du kan styre agenten uden at afbryde dens igangværende arbejde.

**Sådan verificerer du det:** Opdater Codex til version 0.154.0, tjek i modelvælgeren om GPT-6-Astra er tilgængelig for din konto, og afprøv --worktree på en test-session.

**Usikkerhed:** Kilden afslører ikke priser for GPT-6-Astra via Bedrock, hvor stabil worktree-funktionen er i praksis, eller hvornår den forlader det eksperimentelle stadie.

**Sådan verificerer du det:** Har din organisation en Claude-gateway, så tjek gateway.yaml for pricing-feltet, og kontroller at access&#95;control.allow&#95;cidrs faktisk er udfyldt, før du opdaterer.

### 4. Gemini CLI releases: Release v0.60.0-preview.0

**Hvad ændrede sig:** Gemini CLI releases offentliggjorde opdateringen 8. sep. 2026. Gemini CLI v0.60.0-preview.0 retter destinationsvalidering og forbindelsesrouting i CLI'ens web fetch-funktion og håndhæver RFC 9207-udsteder-identifikation i MCP OAuth-flowet. Udgivelsen isolerer også den midlertidige mappe, der bruges af macOS' Seatbelt-sandbox, så sessioner ikke længere deler samme temp-område.

> Kort kildeuddrag: What's Changed fix&#40;core&#41;: improve destination validation and connection routing in web fetch utilities by @diegogodinezr in #29120 fix&#40;core&#41;: enforce RFC…

**Hvorfor det er relevant:** Rettelserne lukker potentielle sikkerhedshuller: strammere validering i web fetch mindsker risikoen for at blive omdirigeret til uventede mål, og den skærpede OAuth-kontrol gør det sværere at forfalske en udsteder i MCP-integrationer. Isoleringen på macOS reducerer risikoen for at sessioner utilsigtet deler filer.

**Sådan verificerer du det:** Opdater til v0.60.0-preview.0 og tjek versionsnummeret med gemini --version, hvis du bruger MCP-forbindelser eller web fetch i din opsætning.

**Usikkerhed:** Det er en preview-udgivelse, så stabiliteten er ikke garanteret, og kilden viser ikke, om rettelserne allerede har påvirket brugere i praksis.

Kilde: [Release v0.60.0-preview.0](https://github.com/google-gemini/gemini-cli/releases/tag/v0.60.0-preview.0)
