### 1. OpenClaw releases: openclaw 2026.7.2-beta.5

**Hvad ændrede sig:** OpenClaw releases offentliggjorde opdateringen 28. jul. 2026. OpenClaw udgiver 2026.7.2-beta.5 med fokus på databeskyttelse: en karantænelagring der overlever skader på hoveddatabasen, krasj-sikre SQLite-snapshots, holdbar filsystempublicering, afvisning af skema-opgraderinger der ville tabe data, og snapshot-genopretning. Udgivelsen tilføjer også holdbar kanallevering, så accepterede beskeder kan genskabes efter genstart af gateway eller lokale nedbrud.

> Kort kildeuddrag: 2026.7.2 Highlights State safety and recovery: protect persisted data with a quarantine store that survives primary-database damage, crash-recoverable SQLite snapshots,…

**Hvorfor det er relevant:** For brugere der kører OpenClaw lokalt eller som selvhostet agent-platform betyder det færre risici for datatab ved nedbrud eller fejlslagne opgraderinger, og beskeder går ikke tabt hvis gatewayen genstarter midt i en samtale.

**Sådan verificerer du det:** Tjek release notes for 2026.7.2-beta.5 på GitHub og se om quarantine-store og snapshot-recovery er aktiveret som standard i din opsætning, før du opgraderer en produktionsinstans.

**Usikkerhed:** Det er en beta-udgivelse, så stabiliteten på tværs af opsætninger er ikke dokumenteret, og det fremgår ikke om funktionerne kræver manuel aktivering eller ekstra diskplads.

Kilde: [openclaw 2026.7.2-beta.5](https://github.com/openclaw/openclaw/releases/tag/v2026.7.2-beta.5)

### 2. OpenAI Codex releases: 0.146.0

**Hvad ændrede sig:** OpenAI Codex releases offentliggjorde opdateringen 29. jul. 2026. OpenAI Codex 0.146.0 tilføjer navngivning af nye sessioner med /new eller /clear, mulighed for at fastgøre vigtige tråde og skifte mellem sidesamtaler uden at lukke dem. Udgivelsen understøtter Agent Plugins-manifester, workspace-plugin-publicering og flere plugin-markedspladser, herunder til Amazon Bedrock og Claude Code. Den tilføjer også forgrening af tråde med paginering af historik, inklusive midlertidige forgreninger der ikke vises i trådlister.

> Kort kildeuddrag: New Features Name new sessions with /new or /clear , pin important threads, and switch between side conversations without closing…

**Hvorfor det er relevant:** For folk der bruger Codex til daglig kodning betyder det bedre overblik i lange sessioner og mulighed for at forgrene en samtale for at afprøve en idé uden at rode den oprindelige tråd til.

**Sådan verificerer du det:** Opdater til 0.146.0 og prøv /new samt fastgørelse af en tråd, og se efter om din foretrukne plugin-markedsplads, fx Claude Code eller Bedrock, dukker op i indstillingerne.

**Usikkerhed:** Det fremgår ikke hvor stabile de nye plugin-markedspladser er, eller om forgrening af tråde har begrænsninger i antal eller opbevaringstid for midlertidige forgreninger.

Kilde: [0.146.0](https://github.com/openai/codex/releases/tag/rust-v0.146.0)

### 4. Claude Code releases: v2.1.219

**Hvad ændrede sig:** Claude Code releases offentliggjorde opdateringen 24. jul. 2026. Claude Code v2.1.219 tilføjer Claude Opus 5 som ny standardmodel for Opus, med 1M kontekst og hurtig tilstand til 10/50 dollar pr. Mtok. Udgivelsen tilføjer indstillingen sandbox.network.strictAllowlist, der afviser ikke-godkendte hosts for sandboxede kommandoer uden at spørge, et DirectoryAdded-hook der udløses når en ny arbejdsmappe registreres, og et nyt felt mcp&#95;server&#95;errors i headless-init-eventet der lister MCP-konfigurationer der er sprunget over.

> Kort kildeuddrag: What's changed Added Claude Opus 5 &#40; claude-opus-5 &#41;, now the default Opus model — 1M context, fast mode at…

**Hvorfor det er relevant:** For brugere der kører kommandoer i sandbox betyder den strikse allowlist, at uventede netværkskald blokeres i stedet for at udløse en godkendelsesprompt, hvilket strammer sikkerheden i automatiserede opsætninger.

**Sådan verificerer du det:** Sæt sandbox.network.strictAllowlist i din konfiguration og test at en ikke-godkendt host faktisk bliver afvist, i stedet for at give en prompt, før du stoler på indstillingen.

**Usikkerhed:** Det fremgår ikke om strictAllowlist er slået til som standard, og prisangivelsen for Opus 5 fast mode er ikke bekræftet for alle regioner eller abonnementstyper.

Kilde: [v2.1.219](https://github.com/anthropics/claude-code/releases/tag/v2.1.219)

### 6. Gemini CLI releases: Release v0.54.0-preview.0

**Hvad ændrede sig:** Gemini CLI releases offentliggjorde opdateringen 28. jul. 2026. Gemini CLI v0.54.0-preview.0 retter en fejl hvor session-ID nu roteres ved model-fallback for at undgå tilstandsafhængige API-fejl, og indfører sanering og indpakning af issue-titler i untrusted&#95;context for at lukke en sikkerhedshul i caretaker-funktionen. Udgivelsen opdaterer også vitest til v3.2.4 og tilføjer package-lock.json-filer.

> Kort kildeuddrag: What's Changed Changelog for v0.53.0-preview.0 by @gemini-cli-robot in #28507 Changelog for v0.52.0 by @gemini-cli-robot in #28508 chore&#40;release&#41;: bump version to…

**Hvorfor det er relevant:** For brugere der oplever fejl når CLI'en falder tilbage til en anden model, bør sessionsfejl blive sjældnere, og saneringen af issue-titler reducerer risikoen for at ondsindet tekst i en GitHub-issue kan påvirke agentens opførsel.

**Sådan verificerer du det:** Opdater til v0.54.0-preview.0 og test model-fallback-scenariet samt hvordan CLI'en håndterer en issue-titel med usædvanlige tegn, før du stoler på rettelserne i produktion.

**Usikkerhed:** Det er en preview-udgivelse, så stabiliteten er ikke garanteret, og det fremgår ikke hvor udbredt problemet med untrusted&#95;context var, eller om andre indgangspunkter har samme sårbarhed.

Kilde: [Release v0.54.0-preview.0](https://github.com/google-gemini/gemini-cli/releases/tag/v0.54.0-preview.0)
