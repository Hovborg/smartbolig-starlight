<Aside type="tip" title="Top Anbefalinger 2025">
- **Smart vægt**: Withings Body+ (~700 kr)
- **Blodtryksmåler**: Withings BPM Connect (~1.000 kr)
- **Søvntracker**: Oura Ring 4 (~3.500 kr)
- **Fitness tracker**: Whoop 4.0 (~240 kr/år)
- **Søvnlys**: Philips SmartSleep (~1.400 kr)
</Aside>

    |------|-------|
    | Max vægt | 180 kg |
    | Batteri | 18 måneder (AAA) |
    | Display | LCD |
  </TabItem>
  <TabItem label="Home Assistant">
    ### Native Withings Integration
    
    ```yaml
    # Indstillinger → Enheder → Withings
    # Kræver Withings Developer konto
    
    # Entiteter der oprettes:
    # - sensor.withings_weight_kg
    # - sensor.withings_fat_mass_kg
    # - sensor.withings_muscle_mass_kg
    # - sensor.withings_bone_mass_kg
    # - sensor.withings_body_water_kg
    # - sensor.withings_fat_ratio_pct
    
    # Eksempel: Morgenvejning notifikation
    automation:
      - alias: "Vægt - Daglig opdatering"
        trigger:
          - platform: state
            entity_id: sensor.withings_weight_kg
        condition:
          - condition: template
            value_template: >
              {{ trigger.from_state.state != trigger.to_state.state }}
        action:
          - service: notify.mobile_app
            data:
              title: "⚖️ Vægt opdateret"
              message: >
                Vægt: {{ states('sensor.withings_weight_kg') }} kg
                Fedt: {{ states('sensor.withings_fat_ratio_pct') }}%
    ```
    
    ### Vægt Trend Automation
    
    ```yaml
    automation:
      - alias: "Vægt - Ugentlig trend"
        trigger:
          - platform: time
            at: "08:00:00"
        condition:
          - condition: time
            weekday:
              - sun
        action:
          - service: notify.mobile_app
            data:
              title: "📊 Ugentlig vægt-rapport"
              message: >
                Aktuel: {{ states('sensor.withings_weight_kg') }} kg
                Ændring: {{ (states('sensor.withings_weight_kg') | float - 
                  state_attr('sensor.withings_weight_kg', 'last_week') | float) | round(1) }} kg
    ```
  </TabItem>
</Tabs>

**Køb:** [Amazon.de](https://amazon.de), [Withings.com](https://withings.com)

## 💍 Fitness Ringe & Trackere

### Oura Ring 4

<Tabs>
  <TabItem label="Oversigt">
    **Pris:** ~3.500 kr / $350 + 50 kr/måned abonnement
    
    **Verdens mest avancerede** smart ring:
    
    - ✅ Søvn tracking (alle faser)
    - ✅ HRV (Heart Rate Variability)
    - ✅ Readiness score
    - ✅ Aktivitetssporing
    - ✅ SpO2 (iltmætning)
    - ✅ Kropstemperatur
    - ✅ Stress/recovery
    - ✅ 7 dages batterilevetid
    
    | Spec | Værdi |
    |------|-------|
    | Batteri | 7 dage |
    | Vandtæt | 100m |
    | Sensorer | PPG, temperatur, accelerometer |
  </TabItem>
  <TabItem label="Home Assistant">
    ### Oura HACS Integration
    
    ```yaml
    # HACS → Integrations → Oura Ring
    # Kræver OAuth2: opret en Oura-udviklerapp og indtast Client ID og Client Secret
    # Understøtter Gen 3, Ring 4 og Ring 5; kræver Home Assistant 2026.3 eller nyere
    
    # Entiteter:
    # - sensor.oura_sleep_score
    # - sensor.oura_readiness_score
    # - sensor.oura_activity_score
    # - sensor.oura_hrv_balance
    # - sensor.oura_resting_heart_rate
    # - sensor.oura_body_temperature
    
    # Eksempel: Readiness-baseret morgen
    automation:
      - alias: "Oura - Lav readiness alarm"
        trigger:
          - platform: numeric_state
            entity_id: sensor.oura_readiness_score
            below: 60
        condition:
          - condition: time
            after: "06:00:00"
            before: "09:00:00"
        action:
          - service: notify.mobile_app
            data:
              title: "😴 Tag det roligt i dag"
              message: >
                Din readiness score er {{ states('sensor.oura_readiness_score') }}.
                Overvej en rolig dag med fokus på restitution.
          # Tænd beroligende lys
          - service: light.turn_on
            entity_id: light.bedroom
            data:
              brightness_pct: 30
              color_temp: 500  # Varm tone
    ```
    
    ### Søvn-baseret Smart Home
    
    ```yaml
    automation:
      - alias: "Søvn score - Justering af hjem"
        trigger:
          - platform: state
            entity_id: sensor.oura_sleep_score
        action:
          - choose:
              # God søvn → Energisk start
              - conditions:
                  - condition: numeric_state
                    entity_id: sensor.oura_sleep_score
                    above: 85
                action:
                  - service: light.turn_on
                    entity_id: light.kitchen
                    data:
                      brightness_pct: 100
                      color_temp: 250
              # Dårlig søvn → Blød start
              - conditions:
                  - condition: numeric_state
                    entity_id: sensor.oura_sleep_score
                    below: 60
                action:
                  - service: light.turn_on
                    entity_id: light.kitchen
                    data:
                      brightness_pct: 50
                      color_temp: 400
    ```
  </TabItem>
</Tabs>

**Køb:** [Ouraring.com](https://ouraring.com)

## 🏠 Smarte Automationer

### Morgen Baseret på Søvndata

```yaml
automation:
  - alias: "Morgen - Tilpas til søvnkvalitet"
    trigger:
      - platform: state
        entity_id: binary_sensor.bedroom_motion
        to: "on"
    condition:
      - condition: time
        after: "05:00:00"
        before: "10:00:00"
    action:
      - choose:
          # God søvn → Energisk morgen
          - conditions:
              - condition: numeric_state
                entity_id: sensor.oura_sleep_score
                above: 80
            sequence:
              - service: light.turn_on
                entity_id: light.bedroom
                data:
                  brightness_pct: 80
                  color_temp: 250
              - service: media_player.play_media
                entity_id: media_player.bedroom_speaker
                data:
                  media_content_type: music
                  media_content_id: "spotify:playlist:energisk_morgen"
          # Dårlig søvn → Blid opvågning
          - conditions:
              - condition: numeric_state
                entity_id: sensor.oura_sleep_score
                below: 60
            sequence:
              - service: light.turn_on
                entity_id: light.bedroom
                data:
                  brightness_pct: 30
                  color_temp: 450
                  transition: 300  # 5 min langsom stigning
```
