Smart belysning er ofte det **første skridt ind i smart home**. Med smart pærer kan du styre lyset med stemmen, automatisere efter solopgang/nedgang, og skabe den perfekte atmosfære. Denne guide hjælper dig med at vælge det rigtige system.

<Aside type="tip" title="Top Anbefalinger 2025">
- **Budget**: IKEA TRÅDFRI - Bedste pris/kvalitet
- **Premium**: Philips Hue - Mest modent økosystem
- **Alternativ**: Innr - Hue-kompatibel til lavere pris
- **LED strips**: WLED på ESP32 - DIY med fantastisk kontrol
- **Dimmere**: Shelly Dimmer 2 - Behold eksisterende pærer
</Aside>

---

## 🔑 Smart Pærer vs Smart Afbrydere

### Hvad skal du vælge?

| Smart Pærer | Smart Afbrydere/Dimmere |
|-------------|-------------------------|
| ✅ Farver og CCT (varm/kold hvid) | ✅ Behold dine eksisterende pærer |
| ✅ Individuel kontrol per pære | ✅ Virker altid fysisk |
| ✅ Nem installation | ✅ Billigere i længden |
| ❌ Virker ikke hvis afbryder slukkes | ❌ Ingen farver |
| ❌ Dyrere per lyspunkt | ❌ Kræver elektriker til installation |

<Aside type="note" title="Vores Anbefaling">
- **Stuer og soveværelser**: Smart pærer for stemning og farver
- **Køkken, bad, entre**: Smart afbrydere/dimmere
- **Udendørs**: Smart afbrydere (vejrbestandige pærer sjældne)
</Aside>

## 💡 IKEA TRÅDFRI - Bedste Pris

<Tabs>
  <TabItem label="Oversigt">
    ### Hvorfor IKEA?
    
    IKEA TRÅDFRI (nu "IKEA Home smart") er det **bedste valg for de fleste**:
    
    - ✅ **Billigste Zigbee pærer** på markedet
    - ✅ Fungerer uden IKEA gateway med ZHA/Zigbee2MQTT
    - ✅ God lyskvalitet og farvegengivelse
    - ✅ 5 års garanti
    - ✅ Nem at købe i IKEA
    - ✅ Fungerer som Zigbee routere
    
    **Ulemper:**
    - ❌ Færre farvevalg end Hue
    - ❌ DIRIGERA gateway kræves for IKEA app
    - ❌ Langsommere opdateringsfrekvens

    ### IKEA Tilbehør
    
    | Produkt | Funktion | Pris |
    |---------|----------|------|
    | **DIRIGERA** | Hub/Gateway | 499 kr |
    | **TRÅDFRI Fjernbetjening** | On/off/dim | 79 kr |
    | **STYRBAR** | 4-knaps fjernbetjening | 149 kr |
    | **RODRET** | Dæmper til væg | 99 kr |
  </TabItem>
  <TabItem label="Installation">
    ### Med Home Assistant (Anbefalet)
    
    Du behøver **IKKE** IKEA's DIRIGERA gateway. Brug i stedet:
    
    1. **Zigbee koordinator** (SkyConnect, Sonoff, ConBee)
    2. **ZHA** eller **Zigbee2MQTT** integration
    
    **Tilføj pære:**
    1. Skru pæren i og tænd
    2. Gå til ZHA/Zigbee2MQTT → Tilføj enhed
    3. Pæren parres automatisk (ny pære) eller reset først
    
    **Reset pære:**
    - Tænd/sluk 6 gange hurtigt (ca. 1 sek intervals)
    - Pæren blinker når den er reset
    
    ### Med DIRIGERA Gateway
    
    Hvis du vil bruge IKEA's egen app:
    1. Tilslut DIRIGERA til router
    2. Download IKEA Home smart app
    3. Tilføj pærer via appen
    4. Integrer med Home Assistant via DIRIGERA integration
  </TabItem>

### 🥇 WLED - Bedste DIY Løsning

WLED er **open source firmware** til ESP32/ESP8266 der styrer addresserbare LED strips (WS2812B, SK6812, etc.).

**Fordele:**
- ✅ Fantastisk effekt bibliotek (100+ effekter)
- ✅ Native Home Assistant integration
- ✅ Segment kontrol
- ✅ Sync mellem flere strips
- ✅ Ekstremt billigt

**Hvad du skal bruge:**
- ESP32 eller ESP8266 (~30 kr)
- WS2812B LED strip (~30-50 kr/meter)
- 5V strømforsyning (2A per meter)

**Køb:** [AliExpress](https://aliexpress.com) (søg "WS2812B 5V")

## 🏠 Home Assistant Automationer

### Populære Belysnings-Automationer

```yaml
# Tænd lys ved bevægelse
automation:
  - alias: "Lys tændes ved bevægelse"
    trigger:
      - platform: state
        entity_id: binary_sensor.gang_motion
        to: "on"
    condition:
      - condition: sun
        after: sunset
    action:
      - service: light.turn_on
        target:
          entity_id: light.gang
        data:
          brightness_pct: 100

# Gradvis dæmpning om aftenen
  - alias: "Aftenbelysning"
    trigger:
      - platform: sun
        event: sunset
        offset: "+01:00:00"
    action:
      - service: light.turn_on
        target:
          entity_id: light.stue
        data:
          color_temp_kelvin: 2700
          brightness_pct: 50
```

### Adaptive Belysning

Home Assistant har en **Adaptive Lighting** integration der automatisk justerer:
- Farvetemperatur efter tid på dagen
- Lysstyrke baseret på sollys
- Gradvis wake-up og sleep modes

**Installation:**
1. HACS → Søg "Adaptive Lighting"
2. Installer og genstart
3. Konfigurer hvilke lys der skal styres
