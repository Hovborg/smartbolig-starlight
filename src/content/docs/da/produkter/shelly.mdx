Shelly er et bulgarsk-baseret firma der laver nogle af de bedste og mest pålidelige smart home produkter på markedet. **Alt virker 100% lokalt** uden cloud, har fantastisk Home Assistant integration, og er designet i EU.

<Aside type="tip" title="Hvorfor Shelly?">
- **Lokal kontrol** - Ingen cloud påkrævet, virker selv uden internet
- **Home Assistant** - Fantastisk integration via WiFi/MQTT
- **Scripting** - Avanceret automatisering direkte på enheden
- **Garanti** - 3 år på Plus/Gen3/Gen4, 5 år på Pro-serien
- **EU-baseret** - Designet og udviklet i Bulgarien
</Aside>

## 🔧 Home Assistant Integration

Shelly har **native integration** i Home Assistant - ingen MQTT påkrævet (men understøttet).

<Steps>
1. Tilslut din Shelly enhed til WiFi via Shelly app
2. Home Assistant finder den automatisk via discovery
3. Klik "Konfigurer" og tilføj enheden
4. Alle entiteter oprettes automatisk
</Steps>

### Avanceret: MQTT

For mere kontrol kan du aktivere MQTT:

1. Gå til Shelly's webinterface (IP-adresse)
2. Settings → MQTT
3. Aktiver MQTT og indtast din broker
4. Brug Mosquitto i Home Assistant
