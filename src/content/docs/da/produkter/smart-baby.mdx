### Nanit Pro

<Tabs>
  <TabItem label="Oversigt">
    **Pris:** ~1.500 kr / $200
    
    Nanit Pro er den **mest avancerede** babymonitor:
    
    - ✅ 1080p HD video (dag & nat)
    - ✅ Vejrtrækningsmonitorering (med Breathing Wear)
    - ✅ Søvnsporing og -analyse
    - ✅ Temperatur & fugtighed
    - ✅ Tovejs lyd
    - ✅ Split-screen (flere kameraer)
    - ✅ Natlampe indbygget
    - ✅ Tips baseret på søvndata
    
    | Spec | Værdi |
    |------|-------|
    | Opløsning | 1080p HD |
    | Synsfelt | 130° |
    | Natlys | Ja (dæmpbar) |
    | Abonnement | Gratis 1 år, derefter betalt |
  </TabItem>
  <TabItem label="Home Assistant">
    ### Via Docker RTMP Restreaming
    
    Nanit kan integreres via RTMP restreaming:
    
    ```yaml
    # Docker container til Nanit
    # https://github.com/indiefan/home_assistant_nanit
    
    # docker-compose.yml
    version: '3'
    services:
      nanit:
        image: indiefan/nanit
        container_name: nanit
        restart: unless-stopped
        volumes:
          - /path/to/data:/data
        environment:
          - NANIT_RTMP_ADDR=192.168.1.100:1935
          - NANIT_LOG_LEVEL=info
        ports:
          - "1935:1935"
    
    # Home Assistant configuration.yaml
    camera:
      - platform: ffmpeg
        name: "Nanit Babyværelse"
        input: rtmp://192.168.1.100:1935/local/BABY_UID
    ```
    
    ### Sensorer fra Nanit
    
    ```yaml
    # REST sensorer (kræver API adgang)
    sensor:
      - platform: template
        sensors:
          baby_room_temperature:
            friendly_name: "Babyværelse Temperatur"
            unit_of_measurement: "°C"
            value_template: "{{ states('sensor.nanit_temperature') }}"
          
          baby_sleep_status:
            friendly_name: "Baby Søvnstatus"
            value_template: >
              {% if is_state('binary_sensor.nanit_sleeping', 'on') %}
                Sover
              {% else %}
                Vågen
              {% endif %}
    ```
  </TabItem>
</Tabs>

**Køb:** [Amazon.de](https://amazon.de), [Nanit.com](https://nanit.com)

    <Aside type="caution" title="Vigtigt">
    Owlet er **ikke en medicinsk enhed** og erstatter ikke lægetilsyn. Brug det som ekstra tryghed, ikke som diagnostisk værktøj.
    </Aside>

  <TabItem label="Home Assistant">
    ### Begrænset Integration
    
    Owlet har pt. ingen officiel HA integration, men data kan hentes via uofficielle metoder:
    
    ```yaml
    # Via Owlet API (uofficiel)
    # Kræver login credentials
    
    # Eksempel sensor template
    sensor:
      - platform: rest
        name: "Owlet Heart Rate"
        resource: https://api.owletdata.com/...
        headers:
          Authorization: !secret owlet_token
        value_template: "{{ value_json.heart_rate }}"
        unit_of_measurement: "BPM"
    
    # Alarm automation
    automation:
      - alias: "Owlet - Lav iltmætning"
        trigger:
          - platform: numeric_state
            entity_id: sensor.owlet_oxygen
            below: 90
        action:
          - service: notify.mobile_app
            data:
              title: "⚠️ OWLET ALARM"
              message: "Lav iltmætning registreret!"
              data:
                priority: high
                ttl: 0
    ```
  </TabItem>
</Tabs>

**Køb:** [Amazon.de](https://amazon.de), [Owletcare.com](https://owletcare.com)

  </TabItem>
  <TabItem label="Home Assistant">
    ### Hatch HACS Integration
    
    ```yaml
    # HACS → Tilføj custom repository
    # https://github.com/dahlb/ha_hatch
    
    # Entiteter:
    # - light.hatch_rest_light
    # - media_player.hatch_rest_sound
    # - switch.hatch_rest_power
    # - number.hatch_rest_volume
    
    # Eksempel: Sengetidsrutine
    automation:
      - alias: "Sengetid - Start Hatch"
        trigger:
          - platform: time
            at: "19:30:00"
        action:
          # Tænd dæmpet orange lys
          - service: light.turn_on
            entity_id: light.hatch_rest_light
            data:
              brightness_pct: 20
              rgb_color: [255, 140, 0]
          # Start hvid støj
          - service: media_player.play_media
            entity_id: media_player.hatch_rest_sound
            data:
              media_content_type: sound
              media_content_id: white_noise
          - service: number.set_value
            entity_id: number.hatch_rest_volume
            data:
              value: 40
    
    # Time-to-Rise automation
    automation:
      - alias: "Morgen - Hatch grønt lys"
        trigger:
          - platform: time
            at: "07:00:00"
        action:
          - service: light.turn_on
            entity_id: light.hatch_rest_light
            data:
              brightness_pct: 50
              rgb_color: [0, 255, 0]  # Grøn = ok at stå op
          - service: media_player.turn_off
            entity_id: media_player.hatch_rest_sound
    ```
  </TabItem>
</Tabs>

## 💡 Smart Natlamper (Budget)

### IKEA TRÅDFRI Natlampe

**Pris:** ~150 kr / $20

**Simpel og billig** løsning:

- ✅ Zigbee (via IKEA hub eller direkte)
- ✅ Dæmpbar
- ✅ Varmt hvidt lys
- ✅ Native HA integration

```yaml
# Via Zigbee2MQTT eller IKEA integration
light:
  - platform: group
    name: "Babyværelse Natlys"
    entities:
      - light.tradfri_nursery
      
automation:
  - alias: "Natlampe - Bevægelse nat"
    trigger:
      - platform: state
        entity_id: binary_sensor.nursery_motion
        to: "on"
    condition:
      - condition: time
        after: "22:00:00"
        before: "06:00:00"
    action:
      - service: light.turn_on
        entity_id: light.tradfri_nursery
        data:
          brightness_pct: 5
          color_temp: 500
```

## 🏠 Smarte Automationer

### Komplet Sengetidsrutine

```yaml
automation:
  - alias: "Baby - Sengetidsrutine"
    trigger:
      - platform: time
        at: input_datetime.baby_bedtime
    action:
      # Dæmp alle lys gradvist
      - service: light.turn_on
        entity_id: light.nursery_main
        data:
          brightness_pct: 30
          color_temp: 500
          transition: 300
      # Start Hatch
      - service: light.turn_on
        entity_id: light.hatch_rest
        data:
          brightness_pct: 15
          rgb_color: [255, 100, 50]
      - service: media_player.play_media
        entity_id: media_player.hatch_rest
        data:
          media_content_id: white_noise
      # Sluk hovedlys efter 15 min
      - delay: "00:15:00"
      - service: light.turn_off
        entity_id: light.nursery_main

  - alias: "Baby - Vågen om natten"
    trigger:
      - platform: state
        entity_id: binary_sensor.nursery_motion
        to: "on"
    condition:
      - condition: time
        after: "22:00:00"
        before: "06:00:00"
    action:
      # Tænd svagt lys til amning/bleskift
      - service: light.turn_on
        entity_id: light.nursery_night_light
        data:
          brightness_pct: 10
          color_temp: 500
      # Sluk efter 10 min uden bevægelse
      - wait_for_trigger:
          - platform: state
            entity_id: binary_sensor.nursery_motion
            to: "off"
            for: "00:10:00"
      - service: light.turn_off
        entity_id: light.nursery_night_light
```

### Morgen Rutine

```yaml
automation:
  - alias: "Baby - God morgen"
    trigger:
      - platform: time
        at: "07:00:00"
    condition:
      - condition: time
        weekday:
          - mon
          - tue
          - wed
          - thu
          - fri
    action:
      # Grønt lys = ok at stå op
      - service: light.turn_on
        entity_id: light.hatch_rest
        data:
          rgb_color: [0, 255, 0]
          brightness_pct: 40
      # Fade hvid støj ud
      - service: number.set_value
        entity_id: number.hatch_volume
        data:
          value: 20
      - delay: "00:05:00"
      - service: media_player.turn_off
        entity_id: media_player.hatch_rest
```
