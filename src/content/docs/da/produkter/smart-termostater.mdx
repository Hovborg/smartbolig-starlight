Smart varme er en af de **bedste investeringer** i smart home. Med smart radiatorventiler (TRV) kan du spare **15-25% på varmeregningen** ved at varme rum individuelt og kun når du er hjemme.

<Aside type="tip" title="Top Anbefalinger 2025">
- **Budget Zigbee TRV**: Sonoff TRVZB (~250 kr)
- **Premium Zigbee TRV**: Aqara E1 (~350 kr)
- **Komplet system**: Tado, Netatmo, Drayton Wiser
- **Home Assistant**: Better Thermostat integration
- **Ekstern sensor**: Aqara temperatur sensor til præcis måling
</Aside>

## 🔑 Hvad Er En Smart TRV?

En **TRV (Thermostatic Radiator Valve)** er en termostatventil der sidder på din radiator. En smart TRV kan:

- ✅ Styres fra telefon eller Home Assistant
- ✅ Følge skemaer (varme op før du vågner)
- ✅ Registrere åbne vinduer og slukke
- ✅ Bruge ekstern temperaturmåler
- ✅ Integreres i automationer

### Smart TRV vs Komplet System

| Zigbee TRV (DIY) | Komplet System (Tado/Netatmo) |
|------------------|-------------------------------|
| ✅ Billigere per enhed | ✅ Plug-and-play opsætning |
| ✅ Fuld kontrol via Home Assistant | ✅ Pæn app til hele familien |
| ✅ Ingen cloud afhængighed | ✅ Geofencing indbygget |
| ✅ Mix forskellige mærker | ✅ Support og garanti |
| ❌ Kræver mere opsætning | ❌ Dyrere |
| ❌ Ingen officiel support | ❌ Cloud-afhængig (de fleste) |
| ❌ Kan ikke kalde på varme* | ❌ Låst til ét økosystem |

*De fleste TRV'er kan kun åbne/lukke ventilen - de kan ikke tænde fyret. Du skal bruge en separat termostat eller relæ til det.

    | Tilslutning | M30x1.5 + adaptere |

    ```yaml
        local_temperature_calibration: auto
    ```

    - sensor.stue_radiator_battery

## 💰 Budget: Moes/Tuya TRV

**Pris:** ~180-200 kr / $25-28

Moes og andre Tuya-baserede TRV'er er de **billigste**, men med kompromisser:

| Fordele | Ulemper |
|---------|---------|
| ✅ Meget billig | ❌ Lavere byggekvalitet |
| ✅ Fungerer med Z2M | ❌ Touch interface (upraktisk) |
| ✅ Mange adaptere | ❌ Display svær at se |
| | ❌ Inkonsistent kvalitet |

<Aside type="caution" title="Advarsel: Moes ved lavt batteri">
Nogle Moes TRV'er åbner ventilen **helt op** når batteriet er lavt. Dette kan føre til overophedning og højere varmeregning. Skift batterier proaktivt!
</Aside>

## 🧠 Better Thermostat Integration

**Better Thermostat** er en HACS integration der gør dine "dumme" TRV'er smarte:

### Funktioner

- ✅ Bruger ekstern temperaturmåler (ikke TRV'ens upræcise sensor)
- ✅ Vindues/dør sensorer (sluk når åben)
- ✅ Vejrudsigt integration
- ✅ Gruppér flere TRV'er per rum
- ✅ Forbedret algoritme for energibesparelse

### Installation

1. **HACS** → Søg "Better Thermostat"
2. **Installer** og genstart
3. **Tilføj integration** → Better Thermostat
4. **Konfigurer**:
   - Vælg din TRV climate entity
   - Vælg ekstern temperatursensor
   - Tilføj vindues/dør sensorer

### Eksempel Konfiguration

```yaml
# configuration.yaml eller via UI
climate:
  - platform: better_thermostat
    name: "Stue Varme"
    thermostat: climate.stue_radiator_trv
    temperature_sensor: sensor.stue_temperatur
    window_sensors:
      - binary_sensor.stue_vindue
    outdoor_sensor: sensor.udendors_temperatur
```

## ⚡ Kald På Varme

De fleste Zigbee TRV'er kan **kun** åbne/lukke ventilen. De kan ikke tænde dit fyr/fjernvarme.

### Løsninger

**1. Eksisterende termostat:**
Behold din normale termostat og lad den kalde på varme. TRV'erne styrer kun lokal temperatur.

**2. Smart relæ:**
Brug en Shelly 1 eller lignende til at tænde/slukke fyret baseret på om nogen TRV har brug for varme.

**3. OpenTherm:**
Hvis du har en modulerende kedel, kan en OpenTherm gateway (fx OTGW) give præcis kontrol.

### Home Assistant Automation

```yaml
# Tænd fyr når en TRV kalder på varme
automation:
  - alias: "Fyr tænd/sluk"
    trigger:
      - platform: template
        value_template: >
          {{ states.climate 
             | selectattr('attributes.hvac_action', 'eq', 'heating')
             | list | count > 0 }}
    action:
      - choose:
          - conditions: "{{ trigger.to_state.state == 'True' }}"
            sequence:
              - service: switch.turn_on
                entity_id: switch.fyr_rele
          - conditions: "{{ trigger.to_state.state == 'False' }}"
            sequence:
              - service: switch.turn_off
                entity_id: switch.fyr_rele
```
