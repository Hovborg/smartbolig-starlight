Vandskader er en af de mest kostbare skader i hjemmet. Med **smart vandovervågning** kan du opdage lækager tidligt og automatisk lukke for vandet før katastrofen sker.

<Aside type="tip" title="Top Anbefalinger 2025">
**Hele-hjem systemer (med automatisk afbrydelse):**
- **Flo by Moen** - Native HA, flow + tryk + temp
- **Phyn Plus** - AI lækagedetektering
- **Flume 2** - Nem DIY installation (ingen afbrydelse)

**Punkt-lækagesensorer:**
- **Aqara Water Leak Sensor** - Zigbee, HomeKit, ~80 kr
- **ThirdReality** - Zigbee, 120dB alarm, HA kompatibel
- **Shelly Flood** - WiFi, direkte HA integration

**Anbefaling:** Aqara sensorer + Aqara Valve Controller T1!
</Aside>

## 🌊 Flo by Moen (Native HA - Anbefalet)

<Tabs>
  <TabItem label="Oversigt">
    **Pris:** ~$500 / ~3.700 kr (Smart Water Shutoff)
    **Pris sensor:** ~$50 / ~370 kr (Smart Leak Detector)
    
    **Native Home Assistant integration:**
    
    - ✅ Vandflow rate (realtid)
    - ✅ Vandtryk måling
    - ✅ Temperatur overvågning
    - ✅ Automatisk vandlukning
    - ✅ Dagligt vandforbrug
    - ✅ Mikro-lækage detektering
    - ✅ Away/Home/Sleep modes
    - ❌ Kræver VVS-installation
    
    <Aside type="note">
    Flo by Moen kan detektere lækager så små som **én dråbe per minut** ved at analysere trykændringer i rørene.
    </Aside>
  </TabItem>
  <TabItem label="Home Assistant">
    ### Native Integration
    
    ```yaml
    # Indstillinger → Enheder → Tilføj Integration
    # Søg "Flo"
    
    # Kræver:
    # - Flo by Moen email
    # - Flo by Moen password
    
    # Entiteter der oprettes:
    # - switch.flo_valve (åbn/luk ventil)
    # - sensor.flo_water_flow_rate
    # - sensor.flo_water_pressure
    # - sensor.flo_water_temperature
    # - sensor.flo_daily_consumption
    # - binary_sensor.flo_pending_alerts
    ```
    
    ### Services
    
    ```yaml
    # Tilgængelige services:
    
    # Kør sundhedstest
    - service: flo.run_health_test
      target:
        entity_id: switch.flo_valve
    
    # Sæt til Away mode
    - service: flo.set_away_mode
      target:
        entity_id: switch.flo_valve
    
    # Sæt til Home mode
    - service: flo.set_home_mode
      target:
        entity_id: switch.flo_valve
    
    # Sæt til Sleep mode (pauser overvågning)
    - service: flo.set_sleep_mode
      target:
        entity_id: switch.flo_valve
    ```
  </TabItem>
  <TabItem label="Automationer">
    ### Automatisk Vandlukning
    
    ```yaml
    automation:
      # Luk vand ved lækage
      - alias: "Vand - Luk ved lækage"
        trigger:
          - platform: state
            entity_id: 
              - binary_sensor.aqara_water_leak_kokken
              - binary_sensor.aqara_water_leak_bad
              - binary_sensor.aqara_water_leak_vaskeri
            to: "on"
        action:
          - service: switch.turn_off
            entity_id: switch.flo_valve
          - service: notify.mobile_app
            data:
              title: "🚰 VAND LUKKET!"
              message: >
                Lækage detekteret: {{ trigger.to_state.name }}
                Vand er automatisk lukket.
              data:
                push:
                  sound:
                    name: "alarm.caf"
                    critical: 1
    
      # Away mode når alle forlader
      - alias: "Vand - Away Mode"
        trigger:
          - platform: state
            entity_id: group.family
            to: "not_home"
            for: "00:30:00"
        action:
          - service: flo.set_away_mode
            target:
              entity_id: switch.flo_valve
    
      # Home mode ved hjemkomst
      - alias: "Vand - Home Mode"
        trigger:
          - platform: state
            entity_id: group.family
            to: "home"
        action:
          - service: flo.set_home_mode
            target:
              entity_id: switch.flo_valve
    ```
  </TabItem>
</Tabs>

**Køb:** [Moen.com](https://www.moen.com/flo), Amazon

## 💧 Phyn Plus

<Tabs>
  <TabItem label="Oversigt">
    **Pris:** ~$600 / ~4.500 kr
    
    **AI-drevet lækagedetektering:**
    
    - ✅ 240 målinger per sekund
    - ✅ Lærer dit hjem's vandmønster
    - ✅ Detekterer utætheder før de bliver store
    - ✅ Automatisk vandlukning
    - ✅ Frostalarm
    - ⚠️ Ingen native HA integration
    - ⚠️ Kun IFTTT eller custom API

    <Aside type="caution" title="HA Integration">
    Phyn har ingen officiel HA integration. Brug IFTTT eller third-party API calls for integration.
    </Aside>
  </TabItem>
  <TabItem label="Home Assistant">
    ### IFTTT Integration
    
    ```yaml
    # Via IFTTT webhooks
    
    # IFTTT Applet:
    # IF: Phyn detects leak
    # THEN: Webhook to HA
    
    automation:
      - alias: "Phyn Lækage via IFTTT"
        trigger:
          - platform: webhook
            webhook_id: phyn_leak_detected
        action:
          - service: notify.all
            data:
              title: "🚰 Phyn: Lækage detekteret!"
              message: "Phyn har detekteret en mulig lækage"
    ```
    
    ### Custom REST Integration (Avanceret)
    
    ```yaml
    # Phyn har uofficiel API
    # Se: github.com/MizterB/homeassistant-phyn
    
    # HACS custom component kræves
    ```
  </TabItem>
</Tabs>

**Køb:** [Phyn.com](https://www.phyn.com)

## 📍 Placering Guide

### Hvor skal du placere lækagesensorer?

| Placering | Prioritet | Risiko |
|-----------|-----------|--------|
| Under opvaskemaskine | ⭐⭐⭐ Høj | Slange brud |
| Under vaskemaskine | ⭐⭐⭐ Høj | Slange brud |
| Under køkkenvask | ⭐⭐⭐ Høj | Utæt fitting |
| Ved vandvarmer | ⭐⭐⭐ Høj | Tank lækage |
| Under toilet | ⭐⭐ Medium | Kondensering, lækage |
| Ved sump pumpe | ⭐⭐ Medium | Oversvømmelse |
| Kælder/bryggers | ⭐⭐ Medium | Grundvand |
| Ved køleskab | ⭐ Lavere | Ismaskine lækage |

<Aside type="tip" title="Sensor Placering">
Placer sensorer på **laveste punkt** hvor vand vil samle sig. Sensor kontakterne skal røre gulvet.
</Aside>

## 🤖 Komplet Automation Suite

```yaml
automation:
  # ===== LÆKAGE RESPONS =====
  
  # Kritisk lækage alarm
  - alias: "Vand - Kritisk Lækage"
    trigger:
      - platform: state
        entity_id:
          - binary_sensor.water_leak_kokken
          - binary_sensor.water_leak_bad
          - binary_sensor.water_leak_vaskeri
          - binary_sensor.water_leak_kalder
        to: "on"
    action:
      # Luk hovedventil
      - service: switch.turn_off
        entity_id: switch.water_main_valve
      
      # Kritisk notifikation
      - service: notify.mobile_app
        data:
          title: "🚨 VANDLÆKAGE!"
          message: >
            {{ trigger.to_state.attributes.friendly_name }}
            Vand er automatisk lukket!
          data:
            push:
              sound:
                name: "alarm.caf"
                critical: 1
                volume: 1.0
            actions:
              - action: "REOPEN_WATER"
                title: "Åbn vand igen"
      
      # Tænd lys
      - service: light.turn_on
        entity_id: light.all_lights
        data:
          brightness_pct: 100
      
      # TTS alarm
      - service: tts.speak
        target:
          entity_id: media_player.kitchen_speaker
        data:
          message: "Advarsel! Vandlækage detekteret. Vandet er lukket."

  # Håndter genåbning
  - alias: "Vand - Genåbn efter alarm"
    trigger:
      - platform: event
        event_type: mobile_app_notification_action
        event_data:
          action: "REOPEN_WATER"
    condition:
      # Kun hvis lækage er stoppet
      - condition: state
        entity_id: binary_sensor.water_leak_kokken
        state: "off"
    action:
      - service: switch.turn_on
        entity_id: switch.water_main_valve
      - service: notify.mobile_app
        data:
          message: "✅ Vand genåbnet"

  # ===== FOREBYGGELSE =====
  
  # Frost advarsel
  - alias: "Vand - Frost Advarsel"
    trigger:
      - platform: numeric_state
        entity_id: sensor.water_pipe_temperature
        below: 4
    action:
      - service: notify.mobile_app
        data:
          title: "❄️ Frost Advarsel"
          message: >
            Vandtemperatur: {{ states('sensor.water_pipe_temperature') }}°C
            Risiko for frosne rør!

  # ===== VANDFORBRUG =====
  
  # Unormalt forbrug
  - alias: "Vand - Unormalt Forbrug"
    trigger:
      - platform: numeric_state
        entity_id: sensor.flo_daily_consumption
        above: 500  # liter
    condition:
      - condition: time
        after: "23:00:00"
    action:
      - service: notify.mobile_app
        data:
          title: "💧 Højt vandforbrug"
          message: >
            Dagens forbrug: {{ states('sensor.flo_daily_consumption') }} liter
            Dette er over normalen.
```
