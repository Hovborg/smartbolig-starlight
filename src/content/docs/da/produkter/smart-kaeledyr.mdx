- **Fodautomat budget**: PETKIT Fresh Element (~400 kr)

## 🍽️ Automatiske Fodautomater

### PETLIBRO Granary - Bedste Valg

<Tabs>
  <TabItem label="Oversigt">
    **Pris:** ~500-700 kr (uden/med kamera)
    
    PETLIBRO er **markedsleder** i smart fodring:
    
    - ✅ 5L kapacitet (op til 20 dage)
    - ✅ 5G + 2.4G WiFi
    - ✅ Op til 10 måltider dagligt
    - ✅ 1-48 portioner per måltid
    - ✅ Personlig stemmeoptagelse
    - ✅ Lav-foder alarm
    - ✅ Rustfri stålskål
    
    **Med kamera (Granary Camera):**
    - 1080P HD video + nattesyn
    - 2-vejs audio
    - Motion detection
    - 145° vidvinkel
    
    | Model | Kamera | Pris ca. |
    |-------|--------|----------|
    | Granary | Nej | 500 kr |
    | Granary Camera | Ja | 700 kr |
  </TabItem>
  <TabItem label="Opsætning">
    ### Nem App-opsætning
    
    1. **Download PETLIBRO app** (iOS/Android)
    2. **Tilslut strøm** og tænd automat
    3. **Tilføj enhed** i app
    4. **Forbind til WiFi** (5G eller 2.4G)
    5. **Opsæt fodringsplan**
    
    **Tips:**
    - Brug originale strømadapter
    - Skift tørremiddel hver 14 dag
    - Tør alle dele før samling
  </TabItem>
  <TabItem label="Home Assistant">
    ### HA Integration (HACS)
    
    Brug **PetLibro custom component**:
    
    ```yaml
    # HACS → Integrations → PetLibro
    # (Søg efter "petlibro")
    
    # Entiteter:
    # - sensor.petlibro_food_level
    # - sensor.petlibro_last_feeding
    # - button.petlibro_feed_now
    # - switch.petlibro_power
    
    # Eksempel: Notifikation ved lav foder
    automation:
      - alias: "Kæledyr - Lav foder alarm"
        trigger:
          - platform: numeric_state
            entity_id: sensor.petlibro_food_level
            below: 20
        action:
          - service: notify.mobile_app
            data:
              title: "🐱 Fodautomat næsten tom"
              message: "Kun {{ states('sensor.petlibro_food_level') }}% foder tilbage"
    
      - alias: "Bekræft fodring"
        trigger:
          - platform: state
            entity_id: sensor.petlibro_last_feeding
        action:
          - service: notify.mobile_app
            data:
              title: "Fodring gennemført"
              message: "Katten er blevet fodret kl. {{ now().strftime('%H:%M') }}"
    ```
  </TabItem>
</Tabs>

**Køb:** [Amazon.de](https://amazon.de), [PetLibro.com](https://petlibro.com)

### Home Assistant via PetKit HACS

```yaml
# PetKit integration understøtter Eversweet
# Kræver BLE relay (anden PetKit enhed)

# Entiteter:
# - sensor.eversweet_water_level
# - sensor.eversweet_filter_life
# - switch.eversweet_power
# - select.eversweet_mode

automation:
  - alias: "Vandfontæne - Skift filter"
    trigger:
      - platform: numeric_state
        entity_id: sensor.eversweet_filter_life
        below: 10
    action:
      - service: notify.mobile_app
        data:
          title: "💧 Filter skal skiftes"
          message: "Vandfontænens filter har kun {{ states('sensor.eversweet_filter_life') }}% tilbage"
```

## 🚪 Smart Kattelem med Chip

### SurePet Microchip Cat Flap

**Pris:** ~1.200-1.800 kr

Lad **kun dine egne katte** ind:

- ✅ Læser mikrochip (RFID)
- ✅ Op til 32 registrerede katte
- ✅ 4 låsetilstande
- ✅ Curfew timer
- ✅ **Native Home Assistant integration!**

### SurePet Connect Hub

For cloud-funktioner + HA:

- Hub priser: ~600 kr
- App-styring af låsestatus
- Historik over ind/ud
- Push-notifikationer

### Home Assistant Integration

```yaml
# Native integration!
# Indstillinger → Enheder → Sure Petcare

# Entiteter:
# - binary_sensor.cat_misser_location (inside/outside)
# - lock.cat_flap (locked/unlocked)
# - sensor.cat_flap_battery

# Eksempel: Spor katten
automation:
  - alias: "Kat er kommet hjem"
    trigger:
      - platform: state
        entity_id: binary_sensor.cat_misser_location
        to: "on"  # inside
    action:
      - service: notify.mobile_app
        data:
          title: "🐱 Misser er hjemme"
          message: "Katten kom ind kl. {{ now().strftime('%H:%M') }}"

  - alias: "Lås kattelem om natten"
    trigger:
      - platform: time
        at: "22:00:00"
    condition:
      - condition: state
        entity_id: binary_sensor.cat_misser_location
        state: "on"  # Kun hvis katten er inde
    action:
      - service: lock.lock
        entity_id: lock.cat_flap

  - alias: "Lås op om morgenen"
    trigger:
      - platform: time
        at: "07:00:00"
    action:
      - service: lock.unlock
        entity_id: lock.cat_flap
```

## 📍 GPS Trackere

### Tractive GPS

**Pris:** ~350 kr + abonnement (~35 kr/md)

**Real-time sporing** af din hund/kat:

- ✅ GPS + WiFi + Cellular
- ✅ Live tracking
- ✅ Virtual fence (geofencing)
- ✅ Aktivitets- og søvnmonitor
- ✅ Vandtæt (IPX7)

### Andre GPS Trackere

| Produkt | Abonnement | Batteri | Pris ca. |
|---------|------------|---------|----------|
| **Tractive** | 35 kr/md | 2-5 dage | 350 kr |
| **Apple AirTag** | Gratis | 1 år | 250 kr |
| **Samsung SmartTag** | Gratis | Måneder | 200 kr |

**Note:** AirTag/SmartTag er Bluetooth - ikke ægte GPS!

### Home Assistant via Tractive

```yaml
# Indbygget integration: Indstillinger → Enheder → Tractive
# Kræver Tractive Premium-abonnement og en konto med e-mail og adgangskode
# (Google/Apple-login understøttes ikke)

# Entiteter:
# - device_tracker.tractive_dog
# - sensor.tractive_battery
# - sensor.tractive_activity

automation:
  - alias: "Hund forlod haven"
    trigger:
      - platform: zone
        entity_id: device_tracker.tractive_dog
        zone: zone.home
        event: leave
    action:
      - service: notify.mobile_app
        data:
          title: "🐕 Hund forlod haven!"
          message: "Max er væk fra hjemmet"
          data:
            actions:
              - action: LOCATE_DOG
                title: "Vis placering"
```

## 🏠 Smarte Automationer

### Fodring ved Hjemkomst

```yaml
automation:
  - alias: "Bonus fodring ved hjemkomst"
    trigger:
      - platform: state
        entity_id: person.brian
        to: "home"
    condition:
      - condition: time
        after: "17:00:00"
        before: "19:00:00"
      - condition: template
        value_template: >
          {{ (as_timestamp(now()) - as_timestamp(states('sensor.petlibro_last_feeding'))) > 14400 }}
    action:
      - service: button.press
        entity_id: button.petlibro_feed_now
```

### Kat-tracking Dashboard

```yaml
# Lovelace kort til kæledyr
type: entities
title: "🐱 Misser Status"
entities:
  - entity: binary_sensor.cat_misser_location
    name: "Lokation"
    icon: mdi:cat
  - entity: sensor.petlibro_last_feeding
    name: "Sidst fodret"
  - entity: sensor.eversweet_water_level
    name: "Vand niveau"
  - entity: sensor.litter_robot_waste_drawer
    name: "Kattebakke"
```

### Nattilstand for Kæledyr

```yaml
automation:
  - alias: "Kæledyr nattilstand"
    trigger:
      - platform: time
        at: "22:00:00"
    action:
      # Lås kattelem (hvis kat er inde)
      - if:
          - condition: state
            entity_id: binary_sensor.cat_misser_location
            state: "on"
        then:
          - service: lock.lock
            entity_id: lock.cat_flap
      # Sluk vandfontæne lys
      - service: switch.turn_off
        entity_id: switch.eversweet_light
      # Skift fodautomat til stille tilstand
      - service: switch.turn_on
        entity_id: switch.petlibro_do_not_disturb
```
