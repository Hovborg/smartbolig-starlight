WiFi smart home enheder er **den nemmeste måde at komme i gang** med smart home. De forbinder direkte til dit WiFi netværk uden ekstra hub. Men pas på - mange kræver cloud og virker ikke uden internet. Denne guide fokuserer på **enheder med lokal kontrol**.

<Aside type="tip" title="Top Anbefalinger 2025">
- **Relæer**: Shelly 1 Mini Gen3, Shelly 1PM Mini Gen3
- **Smart stik**: Shelly Plug S, Nous A1T (med Tasmota)
- **Dimmere**: Shelly Dimmer 2, Shelly Plus Wall Dimmer
- **DIY**: ESP32 med ESPHome
- **Energimåling**: Shelly EM, Shelly Pro 3EM
</Aside>

## 🔑 Lokal Kontrol vs Cloud

### Hvorfor lokal kontrol er vigtigt

| Lokal kontrol | Cloud-afhængig |
|---------------|----------------|
| ✅ Virker uden internet | ❌ Kræver internet |
| ✅ Hurtigere respons | ❌ Langsommere |
| ✅ Privat - ingen data til producent | ❌ Dine data sendes til cloud |
| ✅ Virker selvom firma lukker | ❌ Stopper hvis service nedlægges |
| ✅ Fuld kontrol | ❌ Begrænset funktionalitet |

### Mærker med lokal kontrol

| Mærke | Lokal kontrol | Firmware flash | Note |
|-------|---------------|----------------|------|
| **Shelly** | ✅ Indbygget | Muligt men unødvendigt | ⭐ Anbefalet |
| **Sonoff** | ⚠️ Delvist | Tasmota/ESPHome | Nyere modeller sværere |
| **Tuya/Smart Life** | ❌ Cloud | Tuya-Local eller flash | Mange billige enheder |
| **Tasmota enheder** | ✅ Fuld | Pre-flashed | Lokal fra start |
| **ESPHome DIY** | ✅ Fuld | Du bygger selv | Ultimativ kontrol |

## 🔧 Tasmota & ESPHome

### Tasmota - Færdig Firmware

Tasmota er open source firmware til ESP8266/ESP32 enheder. Giver fuld lokal kontrol via MQTT eller web interface.

**Fordele:**
- ✅ Nem opsætning via web UI
- ✅ Understøtter 1000+ enheder
- ✅ MQTT integration
- ✅ Ingen programmering nødvendig

**Enheder med Tasmota:**
- Nous A1T smart stik (pre-flashed)
- Athom smart stik (pre-flashed)
- Mange Tuya enheder (kræver flash)

**Find kompatible enheder:** [templates.blakadder.com](https://templates.blakadder.com)

### ESPHome - DIY Firmware

ESPHome lader dig bygge custom firmware med YAML konfiguration. Perfekt til DIY projekter.

**Fordele:**
- ✅ Native Home Assistant integration
- ✅ OTA opdateringer
- ✅ On-device automationer
- ✅ Fuld kontrol over alle funktioner
- ✅ ESP32 og ESP8266 support

**Populære DIY projekter:**
- Temperatur/fugtighed sensorer (DHT22, BME280)
- Tilstedeværelsessensorer (LD2410, HLK-LD2450)
- LED strip kontrollere
- Gardin/persienne motorer
- IR blastere (klimaanlæg)

## 💡 Smart Pærer

<Aside type="caution" title="WiFi vs Zigbee Pærer">
**WiFi pærer** belaster dit netværk og har ofte kun cloud kontrol.

**Zigbee pærer** (IKEA, Philips Hue, Innr) er bedre fordi de:
- Fungerer som mesh routere
- Har lokal kontrol
- Bruger mindre strøm på standby

Vi anbefaler Zigbee pærer i stedet for WiFi pærer.
</Aside>

Hvis du alligevel vil have WiFi pærer:

## 🏠 Home Assistant Integration

### Shelly Integration

Shelly enheder opdages **automatisk** i Home Assistant:

1. Tilslut Shelly til WiFi via Shelly app eller Bluetooth
2. Home Assistant finder enheden automatisk
3. Klik "Konfigurer" i Integrationer
4. Færdig!

**Features:**
- Øjeblikkelig status opdatering (push)
- Alle sensorer eksponeret
- Scripting support
- Cover (gardin) kontrol med tilt

### Tasmota Integration

Tasmota enheder kan integreres via:

1. **MQTT (Anbefalet)** - Automatisk discovery
2. **Tasmota integration** - Direkte forbindelse

**MQTT setup:**
```yaml
# I Tasmota console:
SetOption19 1  # Aktiver MQTT discovery
```

### ESPHome Integration

ESPHome enheder tilføjes direkte i Home Assistant:

1. Installer ESPHome Add-on
2. Opret ny enhed med YAML
3. Flash firmware
4. Enheden opdages automatisk
